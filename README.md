# Shardveil
![Shardveil Background](assets/cover.png)

## О проекте
Учебный проект на **Python** с использованием библиотеки **Arcade**: тёмный roguelike в сеттинге упавшего под землю мира.  
История о бывшем рыцаре, ищущем свет среди древних катакомб и шепчущих руин.

Проект находится на **этапе MVP**.
Реализованы базовые механики:

- Главное меню, пауза, экран инвентаря и экран конца игры
- Игрок (Player) и враги (Skeleton)
- Пошаговое движение по тайловой карте 32x32 пикселя  
- Процедурная генерация подземелий BSP
- Контактный бой и простое преследование врагами
- Ресурс света, влияющий на освещение и HUD
- Переход на следующую глубину через лестницу

> Этот проект создаётся для **учебных целей**, как первый опыт разработки roguelike на Python и Arcade.

## Структура проекта
```
shardveil/
├── src/ 
│   ├── main.py         # точка входа: assets/render setup и запуск окна
│   └── sv/             # папка с игровыми модулями
│       ├── game.py     # Arcade Window и связка runtime-систем
│       ├── core/       # настройки, состояние, ввод, коллизии, ходы
│       ├── entities/   # классы сущностей
│       ├── world/      # генерация уровня, тайлы и сборка сцены
│       ├── ui/         # HUD, меню, оверлеи и инвентарь
│       ├── ai/         # логика решений врагов
│       └── items/      # предметы и инвентарь
├── assets/             # папка с графическими ресурсами
└── docs/               # документация проекта
```

## Установка и запуск
Рекомендуется использовать локальное виртуальное окружение `.venv`, чтобы не устанавливать зависимости в системный Python.

Склонируйте репозиторий:
```
git clone https://github.com/skulhex/shardveil
cd shardveil
```

Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows (PowerShell):
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Установите зависимости:
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Запуск игры:
```
python src/main.py
```

Запуск тестов:
```bash
python -m pytest
```
